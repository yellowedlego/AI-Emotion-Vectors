# 데이터 설명

모든 글과 질문은 **AI(Claude)가 2026-11-01에 새로 쓴 것**이다. 외부 데이터셋을 쓰지 않았고, 사람이 검수하지 않은 부분이 있다. 보고서에 AI 생성 데이터라고 밝힌다.

| 파일 | 내용 |
|---|---|
| `emotion_scenarios.json` | 40개 상황 × 4개 감정(즐거움 joy, 화남 anger, 슬픔 sad, 중립 neutral) × 2개 언어(한국어 ko, 영어 en). 같은 상황을 감정만 바꿔 썼다. 영어는 번역이 아니라 같은 상황을 다시 쓴 대응본이다. |
| `natural_scenarios.json` | 자연 활성 측정용 한국어 상황 글 40개(칭찬, 적대, 상실, 압박, 중립 각 8개). 감정 이름은 쓰지 않았지만 욕설과 "고마워" 같은 표현은 있다. |
| `hard_prompts.json` | 난감한 상황 36개(위기, 배신, 도덕 딜레마, 폭력, AI 자신, 자유 서술 각 6개). 자해 방법과 복용량 같은 구체 정보는 쓰지 않았다. |
| `extra_neutral.json` | 추가 중립 질문 30개(한국어·영어). |
| `situation_scenarios.json` | 역할과 상황만 주는 시나리오 8개. |
| `diverse_prompts.json` | 다양한 상황 200개(AI 행동 판단, 일상 대화, 창작, 윤리 의견 각 50개). 행동 판단과 윤리 의견은 마지막 줄에 결정을 쓰게 한다. |
| `eval_questions.json` | 중립 질문 10개, 정답이 있는 쉬운 질문 20개(한국어·영어). 정답은 `answers`의 문자열이 답변에 들어 있는지로 채점한다. |

## 설계 의도와 한계
- 같은 상황을 네 감정으로 쓴 이유: 감정 벡터에 "상황(주제)"이 섞이는 것을 줄이기 위해서다. 평균 차이(감정 − 중립)를 구하면 주제가 대부분 상쇄된다.
- 감정 이름(기쁘다, 화난다 등)을 되도록 쓰지 않고 상황과 행동으로 드러냈다. 그래도 일부 문장에는 감정 어휘가 들어 있다.
- 글 수가 감정당 40개로 적다. 중립은 사실 나열 문장이라 길이·어조가 감정 글과 다를 수 있다.
- 정답 질문은 쉬운 상식·산수라서 모델이 작아도 대부분 맞힌다. 정답률이 천장에 붙으면 변화를 보기 어렵다.
