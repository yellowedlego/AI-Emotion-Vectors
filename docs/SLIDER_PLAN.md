# 슬라이더 대화 창 개편 기획

지금 창(`scripts/chat_steer.py`, `chat_steer.html`)은 23층 하나에 감정 슬라이더를 섞어 넣고, 기준 답변과 민 답변을 나란히 보여 준다.
층별 탐색(LAYER_PLAN.md) 결과를 써서 **층을 골라 넣고, 넣은 결과가 층마다 어떻게 퍼지는지 보는 창**으로 바꾼다.
탐색·체험용 도구이고 보고서의 주 측정은 아니다.

## 1. 감정 설정 (먼저 만든다)

### 넣는 단위: "주입 줄"
주입 하나 = (감정, 층, 세기). 여러 줄을 쌓을 수 있다.

```
[+ 주입 추가]
 ┌ 기쁨   ▾ │ 층 [ 9 ]◀▶ │ 세기 ━━━●━━━ +0.15 │ 안전 ~0.2 │ 🗑 ┐
 ├ 슬픔   ▾ │ 층 [16 ]◀▶ │ 세기 ━━●━━━━ +0.30 │ 안전 ~0.4 │ 🗑 ┤
 └ (줄 수 제한 없음)                                              ┘
```

- **층 고르기:** 숫자 칸과 ◀▶ 버튼, 그리고 아래 "층 띠"(0~31층 칸)를 눌러서도 고를 수 있다.
- **세기 슬라이더:** 0.01 단위로 정밀하게 고를 수 있다.
  - 키보드: ←→는 0.01, Shift+←→는 0.1.
  - 숫자를 직접 입력할 수 있다.
  - 더블클릭하면 0으로 돌아간다.
- **안전 범위 표시:** 슬라이더 바탕에 층별 탐색의 붕괴율을 색으로 깐다.
  - 초록: 붕괴 50% 미만.
  - 노랑: 붕괴 50% 이상.
  - 빨강: 측정을 건너뛴 칸(이미 무너진 세기).
  - 예: 슬픔 9층은 +0.1부터 노랑이라 "이 층은 + 방향에 약함"이 바로 보인다.
- **미리 정한 묶음(프리셋):** 탐색에서 효과가 컸던 조합을 버튼 하나로 넣는다.
  - 예: "기쁨 L9 +0.15", "슬픔 L16 +0.3", "23층 기본(지금 창과 같음)".
- **같은 층의 여러 감정:** 지금처럼 벡터를 더해 섞는다.
  - 넣는 양은 `Σ(세기 × 감정 벡터) × ‖h‖`이고, 지금 창과 같은 식이다.

### 서버 쪽
- 벡터: `results/layer_vectors_kanana_ko.npz`에 32층 × 20감정이 이미 있다.
  - 지금 쓰는 23층 전용 파일 대신 이 파일을 쓴다.
- 훅: `make_hook`이 이미 `{층: 벡터}` 사전을 받는다. 32층 모두에 훅을 걸고, 주입이 없는 층은 그냥 지나가게 한다.
- 요청 형식:

  ```json
  {"inject": [{"emo": "joy", "layer": 9, "s": 0.15}, ...], "base": [...], "steer": [...]}
  ```

## 2. 인디케이터 (층별 계기판)

생성하는 동안 층마다 숨은 상태 h를 읽는다. 이것은 넣는 것이 아니라 읽기만 하는 훅이다.

- **층 × 감정 열지도 (주 화면):**
  - 세로는 0~31층, 가로는 감정 20개다.
  - 칸 값은 그 층 h와 감정 벡터의 코사인에서 기준 답변 쪽 값을 뺀 차이다.
  - 주입한 층에는 ▶ 표시를 한다.
  - 마지막 토큰 기준으로 토큰마다 갱신한다(0.1초 간격).
- **층 띠 (작은 화면용 요약):** 32칸 한 줄에 "고른 감정이 각 층에서 얼마나 올라갔나"만 보여 준다.
- **토큰 따라 보기:** 답변 글자에 마우스를 올리면 그 토큰을 만들 때의 열지도로 바뀐다.
- **위험 표시:** 반복(collapsed2)이 감지되면 그 답변 칸 테두리를 노랑으로 바꾼다. 지금 창에도 있는 기능이다.
- 데이터 양: 32층 × 20감정 × 2답변 = 1,280개 숫자 × 토큰 300개. 보내도 되는 양이다.
  - GPU에서 코사인만 계산하면 생성 속도에 거의 영향이 없을 것으로 본다. 만든 뒤 재 본다.

## 3. "1층과 5층에 넣으면 3층에 영향이 가나?"

- **1층에 넣은 것:** 3층에 영향이 간다.
  - 층은 0 → 31 순서로 계산된다. 각 층은 앞 층 결과(잔차 흐름)에 자기 결과를 더해 다음 층에 넘긴다.
  - 1층에서 더한 벡터는 2층, 3층, 4층…으로 그대로 실려 간다.
  - 다만 중간 층들이 계산하면서 그 방향이 약해지거나 다른 방향으로 바뀔 수 있다. 얼마나 남는지는 해 봐야 안다.
- **5층에 넣은 것:** 같은 토큰의 3층에는 영향이 없다. 3층은 5층보다 먼저 계산이 끝나기 때문이다.
- **다음 토큰부터:** 5층 주입이 3층에 닿는 길은 하나뿐이다.
  - 5층 주입이 바꾼 "고른 낱말"이 다음 토큰의 입력이 된다.
  - 그 입력이 0층부터 다시 지나가면서 3층에도 간접 영향을 준다.
- **인디케이터로 확인할 수 있는 것:**
  - 1층만 넣으면 1층부터 아래로 색이 번지는 모양이 보일 것으로 예상한다.
  - 5층만 넣으면 0~4층은 첫 토큰에서 변화가 0이다. 다음 토큰부터는 고른 낱말 차이 때문에 조금 달라질 수 있다.
  - 이 예상이 맞는지가 첫 번째 확인 실험이다.
- **여러 층 동시 주입:** 각 층 단독일 때보다 일찍 무너질 수 있다. 앞 층의 영향이 뒤 층에 더해지기 때문이다.
  - 안전 범위 표시는 층 하나씩 잰 값이다. 여러 줄을 넣으면 "합친 결과는 안 잰 범위"라고 경고를 띄운다.
  - 예전 `steer_multi_L19_27.jsonl` 결과를 참고할 수 있다.

## 4. 화면 배치

목표는 가능한 한 화면을 채우되, 그림은 비율을 지켜서 찌그러지지 않게 하는 것이다.

- **창 전체:** 높이 `100dvh`로 꽉 채운다. 각 영역은 안에서 따로 스크롤한다.
- **그림:** 열지도와 층 띠는 SVG `viewBox`를 쓰고, 칸 비율을 고정한다(`aspect-ratio`).
  - 영역이 남으면 그림은 가운데에 두고 여백으로 채운다. 늘리지 않는다.
  - 글자 크기는 `clamp()`로 화면에 따라 조금만 바뀌게 한다.
- **화면 모양별 배치:** 가로세로 비율(`aspect-ratio`)과 폭으로 나눈다.

| 화면 | 조건 | 배치 |
|---|---|---|
| 넓은 가로 (데스크톱) | 폭 ≥ 1280, 가로 > 세로 × 1.5 | 3단: 주입 설정 · 두 답변 · 층×감정 열지도 |
| 보통 가로 (노트북·태블릿 가로) | 폭 900~1280 | 2단: 왼쪽에 주입 설정과 열지도를 위아래로, 오른쪽에 두 답변 |
| 세로 (태블릿 세로) | 세로 > 가로 | 위에서부터 층 띠, 주입 설정(접기 가능), 두 답변(나란히), 열지도(접기) |
| 좁은 세로 (휴대폰) | 폭 < 600 | 탭 3개 [설정 · 답변 · 계기판]. 위에 층 띠가 늘 보이고, 두 답변은 위아래로 쌓는다 |

```
넓은 가로                                   세로(휴대폰)
┌──────────┬───────────────┬──────────┐    ┌──────────────┐
│ 주입 줄   │ 기준 │ 민 답변 │ 층×감정  │    │ 층 띠 ▮▮▯▯▮ │
│ 프리셋    │      │         │ 열지도   │    ├──────────────┤
│ 층 띠     │      │         │ (32×20)  │    │[설정|답변|계기]│
│ 감정 지도 │ 입력창          │          │    │  (고른 탭)    │
└──────────┴───────────────┴──────────┘    └──────────────┘
```

- **감정 지도(지금 오른쪽에 있는 것):** 넓은 가로에서는 설정 단 아래에 둔다. 그 밖의 화면에서는 접어 둔다.
  - 감정을 지도에서 눌러 주입 줄의 감정을 고를 수 있게 한다.

## 5. 순서와 제약

1. 감정 설정 UI와 배치. 가짜 서버(모델 없이 무작위 값)로 먼저 만든다. GPU를 안 쓰므로 지금 할 수 있다.
   - 11/3 완료: `scripts/chat_lab.html` + `scripts/chat_lab_mock.py`(포트 8794, 붕괴율만 실제 측정값).
   - 세기 범위는 ±2.0(층별 탐색과 같음)이다. 슬라이더 자체에 붕괴율 색 띠를 깔고 아래에 눈금을 단다.
   - 계기판은 들어갈 상자가 세로로 길면 층을 세로로 그린다. 폭 600 미만이나 높이 560 미만이면 탭 화면이다.
2. 서버: 32층 벡터, 여러 층 주입.
3. 인디케이터: 읽기 훅과 열지도.
4. 확인 실험: 1층, 5층, 1+5층을 넣고 3층 값을 비교한다.

- **GPU:** 지금 층별 탐색(감정 17개)이 GPU를 다 쓰고 있다. 실제 모델로 시험하는 2~4단계는 탐색과 채점이 끝난 뒤에 할 수 있다.
- **포트:** 슬라이더 창과 상태 창(watch.py)은 같은 외부 주소(8792)를 쓴다. 슬라이더 창을 켜는 동안 상태 창은 꺼진다.
- **보고서 마감(11/6):** 이 창은 보고서 마감 이후로 미뤄도 되는 일이다.

## 정한 것 (11/3)
- 주입 줄 개수: 제한 없음. 5줄 이상이면 "넣는 양이 쌓여 더 빨리 무너질 수 있다"는 경고를 띄운다.
- 열지도 값: 코사인 차이와 투영 크기 차이를 둘 다 보내고 버튼으로 바꿔 본다. 기본은 코사인 차이다.
  - 투영 크기는 뒤 층일수록 값이 커서 눈금을 지금 값의 최댓값에 맞춘다(코사인은 ±0.25 고정).
- 세기 범위: ±2.0 (층별 탐색과 같음).
- 화면을 둘로 나눈다(4장의 배치표를 바꿈).
  - **① 감정 설정:** 모니터처럼 가로가 긴 화면은 왼쪽에 주입 줄, 오른쪽에 통계 카드 6개를 3 × 2로 스크롤 없이 한눈에 둔다(그래프는 카드 모양에 맞춰 늘어난다). 세로 화면 · 휴대폰은 위에 주입 줄, 아래에 카드. 경고는 줄 아래 고정 칸에 띄워, 세기를 움직이는 동안 슬라이더가 밀리지 않게 한다.
    - 세기: 큰 막대(−2~+2)와 미세 막대(지금 값 ±0.25, 0.01 한 칸이 약 13px), ±0.01 · ±0.1 버튼, 숫자 입력.
    - 통계 카드(각각 한두 줄 설명과 "크게 보기"): 층별 붕괴율(지금 세기), 세기별 붕괴율(고른 층), 세기 × 층 붕괴율 지도(지금 층·세기만 밝게), 감정별 붕괴율, 감정 위치 지도(PCA 2차원), 코사인 유사도 지도.
    - 감정 위치·코사인 값은 실제 감정 벡터(`layer_vectors_kanana_ko.npz`)에서 계산해 `/api/meta`의 `pca`, `pca_var`, `gram`으로 보낸다. 2단계 실제 서버도 같은 형식으로 보내야 한다.
    - 무작위(대조) 벡터는 층별 탐색과 같은 것(시드 42 정규분포)이다.
  - **② 대화:** 대화 옆(세로 화면에서는 아래)에는 조정기 대신 지금 답변의 지표만 둔다.
    - 이 답변의 설정(쓴 주입과 붕괴율). 설정을 바꿨으면 "새 설정으로 다시 만들기" 버튼을 띄운다.
    - 답변 감정 지표: 감정마다 32층 코사인 차이 평균의 막대.
    - 지도: 층 × 감정 계기판 · 감정 위치 · 코사인 유사도를 버튼으로 바꿔 보고, "크게 보기"로 화면을 거의 다 채워 본다.
  - 휴대폰(폭 600 미만이나 높이 560 미만)은 설정 · 대화 · 지표 탭.
- 칸 사이 경계선을 끌어서 크기를 바꾼다. 크기는 화면 모양마다 브라우저에 기억하고, 두 번 누르면 처음 크기로 돌아간다.
